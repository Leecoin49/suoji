SC-009 的哈希比对（应用开着也能算，用只读打开字节流）：

```powershell
function Hash($p) {
  $fs = [IO.File]::Open($p, 'Open', 'Read', 'ReadWrite')
  $sha = [Security.Cryptography.SHA256]::Create()
  $h = ($sha.ComputeHash($fs) | ForEach-Object { $_.ToString('x2') }) -join ''
  $fs.Close(); $h
}
Hash "$env:APPDATA\com.tool.suoji\suoji.db"
```

注意：**不要用 `Get-FileHash`**，SQLite 开着时会报「正由另一进程使用」。
