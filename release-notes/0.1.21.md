Projects, tags and a flow for each one.

- projects: one level deep, archive instead of delete, and deleting one keeps
  every task it held - those simply become unclassified
- tags: free text, up to ten per task, de-duplicated by name
- a step-by-step flow per project: tick a step and the next one becomes current,
  rename, insert or remove steps at any time, and the list of tasks filed under
  the project sits right below the chain
- file a task into a project while capturing: pick the project chip left of the
  input and the next line lands there; if the project does not exist yet, create
  it from the same picker
- the review panel can now break a stretch down by project or by tag, and offers
  this month, this quarter and this year next to the day presets
- right-click any task for rename, note, file under, tomorrow, inbox and drop;
  click its title to rename it in place

项目、标签，以及每个项目一条进度链。

- 项目：单层，归档代替删除；删除项目不会带走任务，那些任务回到未分类
- 标签：自由文本，每条任务最多十个，按名字去重
- 每个项目一条步骤链：勾掉一步，下一步自动成为「当前」；随时可改名、插入、删除；
  步骤链下面就是这个项目名下的事
- 录入时直接归项目：点输入框左边的项目胶囊，下一条就进那个项目；项目还没建？
  在同一个面板里新建，建好即选中
- 复盘面板可以按项目、按标签拆开看，并把「本月 / 本季 / 本年」和按天预设放在一起
- 右击任意一条琐事：改名、备注、归类、移到明天、回收件箱、不做了；点标题即可就地改名
